# Telco Customer Churn Analysis – Power BI

## 📊 Project Overview

This project analyzes customer churn using Power BI. The dashboard helps identify customer churn patterns based on contract type, payment method, gender, internet service, and customer tenure.

## 🎯 Objectives

* Analyze overall customer churn
* Identify churn patterns across different customer segments
* Compare churn by contract type
* Analyze churn by payment method
* Analyze churn by gender and internet service
* Understand the relationship between customer tenure and churn

## 🛠️ Tools & Technologies

* Power BI
* Power Query
* DAX
* Data Visualization

## 📈 Key Dashboard KPIs

* Total Customers: 7K
* Churned Customers: 2K
* Churn Rate: 26.5%

## 📊 Dashboard Visuals

The dashboard includes:

* Churn by Contract
* Churn by Senior Citizen
* Churn by Payment Method
* Churn by Gender
* Churn by Internet Service
* Churn by Tenure
* Contract slicer
* Internet Service slicer
* Payment Method slicer

## 🔍 Key Insights

* Month-to-month contract customers show higher churn compared with longer-term contracts.
* Churn varies across different payment methods.
* Internet service type is associated with different churn levels.
* Customer tenure provides useful information for understanding churn behavior.
